# 高价值流失客户召回

## 触发词

"流失客户" / "高价值客户" / "召回老客" / "怎么拉复购" / "churn 客户" / "沉睡客户" / "给我一批要跟进的客户"

## 工作流（5 步）

### Step 1 · 定义召回池

```
tool: search_customers
args: {
  stage: "churn",              // 流失阶段
  min_spend: 2000,             // 消费 ≥2000（根据业务调整门槛）
  mode: "retail",              // 或 service
  limit: 50,
  order_by: "last_active"      // 优先最久没活跃的
}
```

**说明**：
- `stage=churn` + `min_spend=高门槛` = 高价值流失
- 如用户没给门槛，默认 retail ≥2000 / service ≥10000
- 也可以 `min_orders: 2`（复购过的才是高价值）

### Step 2 · 批量看时间线（取 Top 10）

召回池出来后，取前 10 位调 timeline：

```
tool: get_customer_timeline
args: { id: <customer_id> }
```

重点看：
- **最后一次消费时间**（越久越紧急）
- **最后一次跟进**（谁跟的？说了啥？）
- **最后一次订单金额**（高客单值得优先）
- **活跃渠道**（偏好企微/门店/线上）
- **有没有 open coupon**（有券未核销可以触发）

### Step 3 · 分层排序

根据 timeline 分析结果，给召回池分层：

| 分层 | 特征 | 优先级 | 建议策略 |
|------|------|--------|----------|
| A 紧急 | 30 天未活跃 + 消费前 10% + 未核销券 | P0 | 专属礼券 + 销售电话 |
| B 重要 | 60 天未活跃 + 消费过 2 次以上 | P1 | 群发关怀 + 企微触达 |
| C 常规 | 90 天未活跃 + 消费过 | P2 | 批量群发活动 |

### Step 4 · 生成跟进清单

给每个 P0/P1 客户输出结构化建议：

```
👤 客户 #123 张三 | VIP 流失 45 天 | 累计消费 ¥8,500

  【最后互动】
    · 最后下单: 2026-08-10 ¥1,999 护肤全套礼盒
    · 最后跟进: 2026-08-15 企微触达，说"出差后回来再说"
    · 当前状态: 未核销券 1 张（¥200）

  【召回建议】
    · 触达方式: 企微 + 短信
    · 话术方向: 限量礼券补发（¥300 无门槛）+ 新出的秋冬系列到店通知
    · 节奏: 今天企微发券 → 明天下午 14:00 短信提醒 → 后天电话确认
```

### Step 5 · 可选：创建群发草稿

如果用户说"直接给他们发"：

```
tool: create_broadcast
args: {
  title: "高价值流失客召回券补发",
  type: "text",
  content: "<根据 Step 4 建议生成具体话术>",
  mode: "retail"
}
```

⚠️ 所有群发默认 **status=待下发**，**不会真的发出去**。创建后要明确告诉用户："已创建群发草稿 #N，包含 XX 字话术，目标客户 XX 位，状态是待下发，需要你确认发送。"

## 安全约束

- 永远不发实时群发，只创建草稿
- 不要编造客户数据， timeline 返回什么就说什么
- 如果召回池为空，直接说"当前没有符合条件的高价值流失客户，可以降低门槛重试"
