# 企微群发专项

## 触发词

"发群发" / "给这批客户发消息" / "企微推送" / "群发短信" / "创建群发" / "发一条推送"

## 工作流（6 步，安全第一）

### Step 1 · 确认目标客群

如果用户没明确指定，先问清楚：
- 是全量客户？还是某个分群？还是按条件筛选？

然后用对应的 tool 拿到候选名单：

```
// 方式 A：按条件筛选
tool: search_customers
args: { stage: "loyal", min_spend: 5000, limit: 200 }

// 方式 B：用现有分群
tool: list_segments
→ 让用户选 → 记下 segment_id
```

### Step 2 · 预估规模

```
// 对筛选条件跑 count
tool: run_custom_analytics
args: { table: "customers", agg: "count", ... 同上过滤条件 }
```

告诉用户："这次群发会覆盖 X 位客户。" 让他确认再继续。

### Step 3 · 文案生成（关键）

根据客群特征自动生成 3 版文案供选：

**文案维度：**
- **渠道风格**：企微消息（亲切短句式）/ 短信（更短更硬）/ 朋友圈/公众号（长图文案）
- **客户分层**：loyal 客（感恩回馈语气）/ churn 客（召回关怀语气）/ new 客（欢迎介绍语气）
- **业务模式**：retail（促销/新品）/ service（案例/白皮书）

**输出 3 版文案：**
```
📢 文案 A（感恩款 · 面向 loyal 客）
  "亲爱的 XX，感谢你一直以来的信任~ 本月专属于你的 VIP 福利已到账..."

📢 文案 B（简洁款 · 适合企微群发）
  "XX 总好，咱们近期服务的企业 X 你还记得吧？现在有个新方案..."

📢 文案 C（急迫款 · 限时活动）
  "最后 24 小时！XX 活动倒计时，专属链接已发你..."
```

### Step 4 · 创建群发草稿

用户选定文案后：

```
tool: create_broadcast
args: {
  title: "<群发标题>",
  type: "text",                    // text / image / article / video
  content: "<最终文案>",
  segment_id: <客群 id 或留空全量>,
  mode: "retail"
}
```

⚠️ 所有群发**状态=待下发**，**不会真的发**。

### Step 5 · 生成发送计划

告诉用户完整的发送计划：
```
📋 群发计划 #N

目标: loyal 客（消费 >5000）| 约 XX 人
渠道: 企微
文案: "XX 文案 A"
状态: 待下发

建议发送节奏:
  · 周一上午 10:00 首次触达
  · 周三下午 14:00 短信提醒未读客户
  · 周五下午 16:00 专属礼券补发

⚠️ 此群发目前只是草稿，需要你在 SCRM 管理后台确认发送。
```

### Step 6 · 查历史发送

```
tool: list_broadcasts
args: { limit: 20 }
```

看之前发过什么、效果怎么样（对比前后 follow_ups 和 orders）。

## 绝对安全红线

- ❌ 永远不跳过"确认客群 → 确认规模 → 确认文案"这三步直接创建群发
- ❌ 永远不把 broadcast 状态设为 "已发送"——系统只支持创建草稿
- ❌ 永远不编造客户数/消费数据，所有数字来自 tool 返回
- ✅ 建议多大胆都行，但写操作必须有用户明确授权
